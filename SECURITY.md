# Security policy

Do not open a public issue containing credentials, tokens, patron information, media URLs, DRM/license data, or security vulnerabilities. Until a private reporting address is established, contact the repository owner directly through GitHub.

OverDrive client credentials must never be committed or embedded in iOS/watchOS binaries. If exposure is suspected, stop using the credential, preserve relevant audit evidence without copying secrets, notify the credential owner, and contact OverDrive immediately as required by the API Agreement.

This project does not accept implementations that scrape, reverse engineer, extract, repackage, or bypass protections on OverDrive/Libby services or content.
